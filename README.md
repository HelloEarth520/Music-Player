# 🎵 MusicPlayer

> 一个基于 Web 技术的本地音乐播放器，彩色渐变极简风格。

> 📱 本项目主要针对**安卓平板**进行主要更新与适配——因为作者本人一直找不到一款真正符合自己使用习惯的播放器，于是AI做了这一款。（deepseek v4+hunyuan3）

## 🚀 快速开始

### 方式一：VSCode + Live Server（推荐开发）
1. 用 VSCode 打开工作区：双击 `MusicPlayer.code-workspace`
2. 安装推荐插件：`Ctrl+Shift+X` → 搜索 Live Server 安装
3. 右键 `index.html` → **Open with Live Server**
4. 浏览器自动打开播放器

### 方式二：直接用浏览器打开
1. 用 Chrome/Edge 打开 `index.html`
2. 点击"📂 打开文件"或拖拽音乐文件到窗口

### 方式三：设置默认播放器
1. 以管理员身份运行 `set-default.bat`
2. 或手动右键 MP3 → 打开方式 → Chrome → 始终使用

## 🎨 功能特性

- 🎨 **动态背景** — 根据当前曲目自动切换渐变氛围色
- 📀 **旋转封面** — 播放时封面黑胶旋转，暂停时停止
- 📂 **文件夹导入** — 一键导入整个音乐文件夹
- 🔀 **随机播放** — 智能随机，不重复
- 🔁 **三种循环** — 顺序 / 列表循环 / 单曲循环
- 🖱️ **拖拽支持** — 直接拖拽文件到窗口
- ⚠️ **格式检测** — 不支持的格式会在列表中标注

## 📦 版本更新 (Changelog)

### v2.17.0（2026-09-06）
- 🌫️ **第三方动态壁纸模糊（方案 A）** — Android 12+（API 31+）改用原生窗口级模糊（`FLAG_BLUR_BEHIND`），实时模糊 WebView 背后的第三方动态壁纸；live 模式下设置「模糊 (Blur)」滑块直接调节壁纸模糊强度（0 关闭、保持清晰直出）。低于 Android 12 自动降级为清晰直出
- 🎤 **歌词交互重构** — 「最近 5 行窗口」升级为全量列表滚动：
  - 当前句始终居中、最大最亮；上下行随距离逐行缩小、颜色渐淡（收敛视差）
  - 歌词可上下滑动浏览；停止滑动 5 秒后自动平滑滚回当前句
  - 当前句右侧新增「— ▶」按钮，点击弹出扁椭圆气泡「从此句播放」，从该句时间点开始播放
  - 歌词字号 10–28px 任意调节不重叠、不裁切（容器高度随字号自适应）
- 同步更新：安卓 APK（versionCode 34）、桌面端、网页版在线演示

### v2.16.1（2026-09-06）
- 🃏 播放列表卡片 — 纵向间距加大；卡片液态玻璃立体投影（边缘阴影 + 内高光）
- 🎤 修复歌词字号超过 15px 时行间重叠 / 显示不全

### v2.16.0（2026-09-06）
- 🎤 **歌手行** — 歌曲名下方新增歌手显示：网易云导出命名（`netease - 歌手 - 歌名`）自动解析歌手
- 🃏 **播放列表卡片** — 每首歌曲带独立小卡片边框，当前播放项整体高亮为主题色
- 🌫️ **整屏壁纸模糊** — 设置「模糊 (Blur)」现在对整屏背景生效（毛玻璃遮罩），滑块 0–40px 实时调节；支持系统壁纸 / 图片 / 纯色背景
  - 注：第三方动态壁纸为系统层（透明窗口外），无法被 CSS 模糊，自动保持清晰直出
- 同步更新：安卓 APK（versionCode 32）、桌面端、网页版在线演示

### v2.15.0
- 🔧 修复 SAF 导入大文件 OOM（流式拷贝到应用缓存，不再整体进内存）
- 🔊 修复 WebAudio 均衡器下 CORS 静音（`crossOrigin=anonymous` + 服务端 CORS 头）
- 📝 **歌词显示** — 歌曲同目录 `.lrc` 最近 5 行随播放滚动；支持标准 / 网易云逐字 / JSON 词条格式；字号、颜色、炫彩流逝可自定义
